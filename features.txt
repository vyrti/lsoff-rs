================================================================================
  eBPF REAL-TIME ENGINE (aya)                      [ HIGH EFFORT ]
================================================================================

  Full in-kernel eBPF socket lifecycle tracing via aya framework.
  Replaces polling with zero-cost kernel-push event stream.
  Linux only. Requires CAP_BPF / root. Kernel >= 5.8 for RingBuf.

  --- SHARED EVENT TYPES (lsoff-rs-common/src/lib.rs) ---

    #![no_std]

    /// Event types pushed from kernel to userspace via RingBuf.
    #[repr(C)]
    #[derive(Clone, Copy)]
    pub enum SocketEventKind {
        ListenStart = 0,    // TCP socket entered LISTEN state
        ListenStop  = 1,    // TCP socket left LISTEN state (close)
        UdpBind     = 2,    // UDP socket bound to port
        UdpClose    = 3,    // UDP socket closed
        StateChange = 4,    // TCP state transition (for --all mode)
    }

    #[repr(C)]
    #[derive(Clone, Copy)]
    pub struct SocketEvent {
        pub kind:      u32,       // SocketEventKind
        pub pid:       u32,       // tgid (userspace PID)
        pub tid:       u32,       // thread ID
        pub af:        u16,       // AF_INET (2) or AF_INET6 (10)
        pub proto:     u8,        // IPPROTO_TCP (6) or IPPROTO_UDP (17)
        pub pad:       u8,
        pub sport:     u16,       // local port (host byte order)
        pub dport:     u16,       // remote port (0 for listeners)
        pub saddr:     [u8; 16],  // local address (4 bytes IPv4, 16 bytes IPv6)
        pub daddr:     [u8; 16],  // remote address
        pub old_state: u8,        // previous TCP state
        pub new_state: u8,        // new TCP state
        pub comm:      [u8; 16],  // process comm (TASK_COMM_LEN)
        pub timestamp: u64,       // ktime_get_ns()
    }

    // Size: 80 bytes per event (fits in eBPF stack, cache-line friendly)

    #[cfg(feature = "user")]
    unsafe impl aya::Pod for SocketEvent {}


  --- KERNEL-SIDE eBPF PROGRAMS (lsoff-rs-ebpf/src/main.rs) ---

    #![no_std]
    #![no_main]

    Tracepoints to attach:

    1. sock:inet_sock_set_state  (kernel >= 4.16)
       - Fires on EVERY TCP state transition.
       - Fields: protocol, oldstate, newstate, sport, dport, saddr, daddr, family.
       - Filter: newstate == TCP_LISTEN → emit ListenStart event.
       - Filter: oldstate == TCP_LISTEN → emit ListenStop event.
       - Filter: newstate == TCP_ESTABLISHED → emit StateChange (for --all).
       - This single tracepoint replaces both inet_csk_listen_start and tcp_close.

    2. kprobe:udp_lib_get_port  (or kprobe:udp_v4_get_port / udp_v6_get_port)
       - Fires when a UDP socket successfully binds to a port.
       - Extract: sk->__sk_common.skc_num (bound port).
       - Emit UdpBind event.

    3. kprobe:udp_destroy_sock  (or tracepoint:udp:udp_destroy_sock if available)
       - Fires when a UDP socket is being torn down.
       - Emit UdpClose event.

    Maps:

    #[map]
    static EVENTS: RingBuf = RingBuf::with_byte_size(256 * 1024, 0);
    //
    // 256 KB ring buffer. At 80 bytes/event, holds ~3200 events before wrap.
    // RingBuf (kernel >= 5.8) provides:
    //   - Single shared buffer across all CPUs (no per-CPU waste)
    //   - Strong event ordering (unlike PerfEventArray)
    //   - Zero-copy reserve/commit pattern (no stack copies)
    //   - Automatic drop counting

    Event emission pattern (reserve-commit, avoids 512-byte stack limit):

    fn emit_event(kind: u32, ctx: &TracePointContext, ...) {
        if let Some(mut entry) = EVENTS.reserve::<SocketEvent>(0) {
            let ev = entry.as_mut_ptr();
            unsafe {
                (*ev).kind = kind;
                (*ev).pid = (bpf_get_current_pid_tgid() >> 32) as u32;
                (*ev).sport = sport;
                // ... fill remaining fields
                bpf_get_current_comm(&mut (*ev).comm);
                (*ev).timestamp = bpf_ktime_get_ns();
            }
            entry.submit(0);
        }
    }

  --- BUILD SYSTEM (xtask/src/main.rs) ---

    cargo xtask build-ebpf:
      1. Invoke cargo build on lsoff-rs-ebpf/ with:
           --target bpfel-unknown-none
           -Z build-std=core
           RUSTFLAGS containing bpf-linker path
      2. Output: target/bpfel-unknown-none/release/lsoff-rs-ebpf
      3. Embedded into userspace binary via include_bytes_aligned!()

    cargo xtask build:
      1. Build eBPF first (above)
      2. Build userspace: cargo build --release

    CI integration:
      - eBPF build only on Linux (feature-gated behind cfg(feature = "ebpf"))
      - Non-Linux platforms: stub remains as-is, no eBPF deps pulled in
      - GitHub Actions: install bpf-linker, nightly toolchain for eBPF crate


  --- RUNTIME BEHAVIOR ---

    lsoff-rs (no flags):
      1. Attempt EbpfSocketEngine::try_attach()
      2. If CAP_BPF / root / kernel >= 5.8:
           → eBPF active: real-time push events, zero polling
           → TUI shows ⚡ indicator in title bar
      3. If not:
           → Graceful fallback to existing polling engine
           → No error, no noise. User doesn't need to know.

    lsoff-rs --ebpf:
      Force eBPF mode. Error if not available (permission/kernel too old).

    lsoff-rs --no-ebpf:
      Force polling mode even if eBPF is available.


  --- FEATURE GATING ---

    Cargo.toml:
      [features]
      default = []
      ebpf = ["aya", "aya-log"]

    This keeps the default build lightweight (no nightly, no bpf-linker).
    eBPF is opt-in: cargo build --features ebpf


  --- ADVANTAGES OVER POLLING ---

    Current (polling):
      - list_listeners() → snapshot → sleep 2s → snapshot → diff
      - Misses short-lived sockets that open and close between polls
      - CPU cost scales with number of running processes (O(processes))

    eBPF (event-driven):
      - Kernel pushes events at the exact moment of state change
      - Zero CPU cost when no sockets change (0% idle overhead)
      - Catches ALL events including sub-second ephemeral sockets
      - O(1) per event, independent of total process count
      - Enriches TUI with real-time open/close animations
